# Go, Pack & See — Telegram-бот

**Интерактивный путеводитель по регионам России в Telegram.**
Выбирайте регион, читайте о нём и проходите пошаговые маршруты с историей, фотографиями и ссылками на карту — прямо в чате, без установки отдельного приложения.

## Возможности

- **Каталог регионов.** Главное меню строится автоматически из `regions.json` — новый регион появляется в боте без правок кода.
- **Раздел «О регионе».** Краткая справка с иллюстрацией, оформленная в Markdown.
- **Пошаговые маршруты.** Каждый маршрут — набор «страниц»-остановок с быстрой навигацией: ⏪ в начало, ⬅️ назад, ➡️ вперёд, ⏩ в конец.
- **Кнопка «Показать на карте».** Для любой страницы маршрута можно указать ссылку на точку на карте; если ссылки нет, кнопка не показывается.
- **Богатое оформление.** Контент хранится в обычных `.md`-файлах и отправляется как rich-сообщения Telegram (заголовки, цитаты, изображения, выделение).
- **Навигация в одном сообщении.** Меню переключаются редактированием текущего сообщения, поэтому чат не засоряется.
- **Ссылка «К началу страницы»** автоматически добавляется к длинным текстам.
- **Предложения регионов и баг-репорты.** Пользователи могут предложить новый регион/маршрут или сообщить об ошибке — всё сохраняется в JSONL.
- **Устойчивость к ошибкам.** Единый обработчик ошибок сообщает пользователю о проблеме и ведёт журнал, а безобидные ситуации (например, `message is not modified`) игнорирует.

## Как это выглядит для пользователя

```
/start
 └─ Главное меню ─ список регионов
     └─ Регион
         ├─ О регионе ─ справка
         └─ Маршруты
             └─ Маршрут (страницы 1…N)
                 ├─ Показать на карте
                 └─ ⏪  ⬅️  ➡️  ⏩
```

## Быстрый старт

### Требования

- Python **3.12+**
- [uv](https://docs.astral.sh/uv/) (рекомендуется) или `pip`
- Токен бота от [@BotFather](https://t.me/BotFather)

### Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone <URL-репозитория>
cd Go-Pack-See-Telegram-Bot

# 2. Установите зависимости
uv sync

# 3. Создайте файл с настройками и впишите токен
cp .env.example .env

# 4. Запустите бота (long polling)
PYTHONPATH=src uv run python main.py
```

> Модули импортируются как `handlers`, `keyboards`, `utilities`, поэтому каталог `src` должен быть в `PYTHONPATH` (в PyCharm достаточно пометить `src` как *Sources Root*).

Установка без `uv`:

```bash
python -m venv .venv && source .venv/bin/activate
pip install "aiogram>=3.31.0" "aiofiles>=25.1.0" "python-dotenv>=1.0.0"
PYTHONPATH=src python main.py
```

Остановить бота — `Ctrl + C`.

## Конфигурация

Настройки читаются из `.env` (через `python-dotenv`).

| Переменная  | Обязательна | Описание                          |
|-------------|:-----------:|-----------------------------------|
| `BOT_TOKEN` |     да      | Токен Telegram-бота от @BotFather |

Если `BOT_TOKEN` не задан, бот завершится с сообщением `BOT_TOKEN not set`.

> ⚠️ **Никогда не коммитьте `.env`.** Файл уже находится в `.gitignore`; если токен попадал в публичный репозиторий или архив — перевыпустите его через `/revoke` в @BotFather.

## Команды бота

| Команда       | Описание                                                          |
|---------------|-------------------------------------------------------------------|
| `/start`      | Приветствие и главное меню                                        |
| `/main_menu`  | Вернуться в главное меню (сбрасывает любой незавершённый диалог)  |
| `/suggest`    | Предложить новый регион и, по желанию, идею маршрута              |
| `/bug_report` | Сообщить об ошибке в работе бота                                  |

Диалоги `/suggest` и `/bug_report` реализованы на FSM aiogram; на любом шаге их можно прервать кнопкой «Отмена», а необязательный шаг — пропустить.

## Архитектура

Бот построен на **aiogram 3** и разделён на независимые слои:

| Слой             | Каталог / файл                      | Ответственность                                                     |
|------------------|-------------------------------------|---------------------------------------------------------------------|
| Точка входа      | `main.py`                           | Загрузка `.env`, сборка `Dispatcher`, запуск polling                |
| Обработчики      | `src/handlers/`                     | `command_handlers` (команды и FSM), `navigation_handlers` (inline-навигация), `error_handlers` (глобальные ошибки) |
| Клавиатуры       | `src/keyboards/`                    | Построение inline-клавиатур из каталога регионов                    |
| Callback-данные  | `src/data/callbacks.py`             | Типизированный `Nav(action, region, tour, page)` на `CallbackData`  |
| Состояния FSM    | `src/data/forms.py`                 | Состояния диалогов предложений и баг-репортов                       |
| Загрузка данных  | `src/utilities/load_data.py`        | Каталог регионов (кэшируется `lru_cache`), асинхронное чтение Markdown |
| Сохранение данных| `src/utilities/save_data.py`        | Потокобезопасная дозапись в JSONL                                   |
| Middleware       | `src/middlewares.py`                | Автоматический `callback.answer()`, чтобы кнопка не «зависала»      |
| Контент          | `src/data/markdown/`, `src/data/jsons/` | Тексты и описание каталога — отдельно от кода                    |

**Ключевые решения**

- **Контент отделён от кода.** Тексты — это Markdown-файлы, структура каталога — JSON. Редактору не нужно трогать Python.
- **Валидация идентификаторов.** Slug региона и маршрута проверяются регулярным выражением `[a-z0-9_]+`, что исключает подстановку произвольных путей при чтении файлов.
- **Неизменяемые модели.** `Region` и `Tour` — `frozen` dataclass со `slots`.
- **Единый путь ошибок.** Неизвестный регион, маршрут или отсутствующий файл поднимают `UnknownResourceError`, который перехватывается глобальным обработчиком.
- **Ручной ответ на callback там, где он нужен.** Для листания маршрутов флаг `manual_answer` отключает автоответ middleware, чтобы показать alert на границах маршрута («Вы находитесь на первой / последней странице»).
- **Безопасная запись.** Запись в JSONL защищена `asyncio.Lock`, строки пишутся атомарно по одной.

## Как добавить новый регион и маршрут

Код менять не нужно — достаточно данных.

**1. Опишите регион в `src/data/jsons/regions.json`:**

```json
{
  "tatarstan": {
    "title": "Татарстан",
    "tours": [
      {
        "title": "Казань",
        "slug": "kazan",
        "pages": 10,
        "map_links": {
          "1": "https://example.com/map-point-1",
          "3": "https://example.com/map-point-3"
        }
      }
    ]
  }
}
```

| Поле        | Описание                                                                                     |
|-------------|----------------------------------------------------------------------------------------------|
| ключ региона| Slug: только `a-z`, `0-9`, `_`                                                               |
| `title`     | Название, отображаемое на кнопке                                                             |
| `tours[].slug`  | Slug маршрута (тот же формат)                                                            |
| `tours[].pages` | Количество страниц маршрута                                                              |
| `tours[].map_links` | Необязательно: номер страницы → ссылка на карту. Для остальных страниц кнопка скрыта |

**2. Создайте Markdown-файлы по соглашению об именах:**

| Что                 | Путь                                                         |
|---------------------|--------------------------------------------------------------|
| Меню региона        | `src/data/markdown/menus/{region}_menu.md`                   |
| О регионе           | `src/data/markdown/about_region/about_{region}.md`           |
| Страница маршрута   | `src/data/markdown/tours/{region}_{tour}_{page}.md`          |

Например, 3-я страница маршрута «Казань» в Татарстане — `tatarstan_kazan_3.md`.

**3. Перезапустите бота.** Каталог кэшируется при первом обращении, поэтому изменения в `regions.json` подхватываются после перезапуска.

**Рекомендации**

- Держите slug короткими: они упаковываются в `callback_data`, а у Telegram есть ограничение на её размер (64 байта).
- Начинайте страницу с изображения (`![Alt](url)`), а заканчивайте подводкой к следующей остановке — так маршрут читается как единая история.
- Текст длиннее 700 символов автоматически получает ссылку «К началу страницы».

## Обратная связь от пользователей

Предложения и баг-репорты сохраняются в формате [JSON Lines](https://jsonlines.org/) — одна запись на строку, UTF-8, время в UTC.

`suggestions.jsonl`:

```json
{"created_at":"2026-10-08T16:27:22+00:00","user_id":123456789,"username":"example","region_name":"Пермский край","tour":null}
```

`bug_reports.jsonl`:

```json
{"created_at":"2026-10-08T07:58:59+00:00","user_id":123456789,"username":"example","report":"Описание проблемы"}
```

Быстрый просмотр:

```bash
jq . src/data/jsons/suggestions.jsonl
```

> Файлы содержат персональные данные пользователей (ID и username) — не публикуйте их и не добавляйте в репозиторий. Убедитесь, что оба пути перечислены в `.gitignore`.

## Разработка

Инструменты разработки устанавливаются группой `dev`:

```bash
uv sync --group dev

uv run ruff check .          # линтер (E, F, I, UP, B, ASYNC; длина строки 100)
uv run ruff format .         # форматирование
uv run mypy .                # проверка типов
```

**Стек:** Python 3.12 · [aiogram](https://docs.aiogram.dev/) 3.31+ · aiofiles · python-dotenv · ruff · mypy.

**Рабочий процесс.** Изменения вносятся в отдельных ветках через pull request.
